# PS 새 달 모듈 세팅

전체 과정(파일 생성, modules.xml 등록, 커밋)을 `new-month.sh`가 전부 처리한다. 사용자는 인자를 넘길 필요 없이 "새 달 세팅해줘" 정도만 말하면 되고, 스크립트 호출에 필요한 인자는 호출자(이 스킬을 실행하는 Claude)가 자동으로 채운다.

## 실행

```
<이 스킬의 base directory>/new-month.sh [YYYY-MM] "<현재 실행 중인 모델명, 예: Claude Sonnet 5>"
```

- 1번째 인자(연월)는 생략하면 스크립트가 오늘 날짜 기준으로 정한다. 특별히 다른 달을 지정해야 하는 경우가 아니면 생략한다.
- 2번째 인자(모델명)는 **항상 호출자가 채운다** — 이 스킬을 실행하는 시점의 실제 모델명("Claude " 접두사 포함, 예: `"Claude Sonnet 5"`)을 넣는다. 과거 세션 기록이나 다른 곳에서 본 값을 베끼지 말고, 지금 이 스킬을 실행하는 자기 자신의 모델명을 쓴다. 모델명을 모르면 생략 가능(스크립트가 "Claude Code"로 대체).
- 이미 해당 `{year}-{month}/` 디렉터리가 존재하면 스크립트가 아무것도 하지 않고 비정상 종료(exit 1)한다 — 이 경우 이미 존재한다고 사용자에게 보고하고 끝낸다.
- 스크립트가 하는 일: `{year}-{month}/src/` 생성 → `{year}-{month}.iml` 생성(다른 달과 바이트 단위로 동일한 템플릿) → `.idea/modules.xml`에 등록 → `git add`+`git commit -m "chore: {year}-{month} 모듈 세팅"`(co-author 트레일러 포함).
- push는 하지 않는다 — push는 사용자가 직접 한다.

## 실패 시

스크립트가 0이 아닌 코드로 종료하면 재시도 없이 stderr 메시지를 그대로 사용자에게 보고한다.
